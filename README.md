# Medic

> **一个值班工程师 Agent。** 它在一套真实运行的微服务系统上接收告警，自主诊断、
> 定位根因、经受控执行层实施处置，并以「服务是否真的恢复」作为判据自动评测。

判据不是标注，是物理事实：健康探针从红变绿，或者没变。

---

## 它解决什么

告警系统能告诉你「checkout 的 P99 涨到 3 秒」，但不能告诉你为什么。
值班工程师被叫醒之后要做的事是一条**分支不可预知的链路**：

```
错误率涨了吗 → 没涨，是慢了
  全慢还是长尾 → P99 爆炸，长尾
    卡在哪一段 → 下游 productcatalog
      它自己慢还是它的下游慢 → 递归
```

第一步的答案决定第二步查什么。这写不成检查清单——**这就是 Agent 的正当性所在**。

但这个论断必须被验证而不是被假设，所以项目里有一个对照组就叫「固定检查清单」。
如果 Agent 赢不过它，结论会如实写在这里。

## 架构

```
┌────────────────────────────────────────────────┐
│ SUT — OpenTelemetry Demo (docker compose)      │
│ 15 个多语言微服务 + Prometheus / Jaeger / 日志  │
└──────────┬─────────────────────┬───────────────┘
     只读观测                受控处置
           ▼                     ▲
┌────────────────────┐  ┌────────┴─────────────────┐
│ Agent   (Python)   │  │ Gateway (Go)             │
│ 假设-验证循环       │─▶│ 动作网关 / Saga 补偿      │
│ 结构化决策输出      │  │ 幂等 / 确认门 / 熔断 / 审计│
└────────────────────┘  └──────────────────────────┘
           ▲
┌──────────┴─────────────────────────────────────┐
│ Runner + Injector (Go)                          │
│ 注入故障 → 告警 → 交给 Agent → 收轨迹 → 判分 → 复原│
└─────────────────────────────────────────────────┘
```

**Go 管副作用，Python 管推理。** Agent 没有任何写权限，
它只能向 Gateway 提议动作，由 Gateway 决定执行、拦截或要求人确认。
